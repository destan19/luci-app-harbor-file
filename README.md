# Harbor File：让 OpenWrt 像 Windows 一样管理文件

Harbor File 是一个面向 OpenWrt 的独立文件管理插件。安装后，用户可以直接在 LuCI 网页界面中浏览、查看、编辑和管理路由器文件，不再需要频繁登录 SSH、手写命令或在不同工具之间来回切换。

它的目标很直接：把 OpenWrt 上原本偏命令行的文件操作，变成更接近 Windows 资源管理器的可视化体验。

## 类 Windows 的文件管理体验

Harbor File 提供类似 Windows 文件管理器的交互方式，包括“快速访问”“此设备”“磁盘空间”“文件夹列表”“面包屑路径”和右键菜单。用户可以像在电脑上管理文件一样，在不同目录之间切换、返回上一级、刷新目录、查看文件属性，并通过图标、磁贴或列表方式浏览文件。

对于不熟悉 Linux 目录结构的用户，这种体验会明显降低使用门槛；对于熟悉 OpenWrt 的用户，它也能减少大量重复的 SSH 操作。

## 常用目录与快速访问

插件内置常用目录入口，例如 Documents、Pictures、Videos、Music、Downloads 等，并支持设置用户自己的 Home directory。常用目录会自动创建并显示在“快速访问”中，适合保存配置备份、下载文件、图片、视频、安装包和临时资料。

这让路由器不再只是一个系统设备，也可以作为轻量文件工作区使用。

## 磁盘与存储空间展示

Harbor File 会展示设备上的存储空间，让用户直观看到系统盘、挂载盘、外接存储等目录入口。对于带 USB 存储、NAS 轻量场景、旁路由或软路由设备，这个能力非常实用。

用户可以直接进入不同挂载目录，查看文件大小、类型、修改时间和目录内容。

## 完整的文件操作能力

插件支持常见文件管理操作：

- 新建文件夹
- 新建文件
- 重命名
- 删除
- 复制
- 剪切
- 粘贴
- 复制到指定目录
- 移动到指定目录
- 批量复制
- 批量移动
- 批量删除
- 文件上传
- 文件下载

这些操作都集成在页面工具栏和右键菜单中，使用方式接近桌面文件管理器。对于配置迁移、日志导出、插件安装包上传、脚本维护等场景，使用成本会低很多。

## 文本编辑与二进制查看

Harbor File 可以直接打开常见文本文件，例如 txt、log、conf、cfg、ini、json、xml、csv、lua、sh、md、yaml、html、css、js 等。用户可以在浏览器中查看和编辑配置、脚本、日志片段，保存后立即写回设备。

对于非文本文件，插件提供二进制查看能力，支持按偏移和长度读取内容，并以 Hex 和 ASCII 形式展示。调试异常文件、检查头部信息或确认文件内容时很方便。

## 图片、PDF、视频预览

插件内置多类型预览能力：

- 图片预览：支持 png、jpg、jpeg、gif、bmp、webp、svg、ico、avif 等格式。
- PDF 预览：可以在浏览器支持的情况下直接打开 PDF。
- 视频预览：支持 mp4、webm、ogg、ogv、mov、m4v、mkv、avi 等常见格式。

这让用户不必下载文件到本地再确认内容，尤其适合管理挂载盘、媒体目录、日志截图、备份资料等。

## 图片缩略图与缓存

Harbor File 支持图片缩略图功能。开启后，可以在图片目录中生成缓存缩略图，并在图标或磁贴视图中展示。缩略图会缓存到用户目录下，后续浏览更快。


## 支持 IPK 和 APK 安装包

Harbor File 对 OpenWrt 包管理做了专门适配，支持直接识别并安装：

- `.ipk` 安装包，适用于传统 OpenWrt/opkg 环境。
- `.apk` 安装包，适用于使用 apk 包管理的新版本 OpenWrt 环境。

用户可以把安装包上传到设备，然后像在 Windows 中双击安装程序一样，在文件管理器里直接触发安装。插件会自动检测可用的安装器，必要时更新包索引，并展示安装进度、日志、退出码和最终结果。

这意味着它不仅能在传统 OpenWrt 上使用，也能覆盖采用 apk 包格式的新 OpenWrt 版本。

## 上传体验与空间保护

插件支持浏览器上传文件到指定目录，并显示上传进度、上传速度和完成状态。上传前会检查目标目录和剩余空间，避免在可用空间过低时继续写入，降低把系统盘写满的风险。

对于目录冲突、特殊文件冲突、不可写路径等情况，也会给出明确提示。

## 终端联动

如果设备安装并配置了 ttyd，Harbor File 可以从当前目录直接打开 Web Terminal。用户在文件管理器中定位到某个目录后，可以一键进入对应路径的终端环境，图形界面和命令行可以自然衔接。

这对高级用户尤其有价值：日常文件管理用网页完成，需要精细操作时再进入终端。

## 安全与权限控制

OpenWrt 的系统目录非常敏感，误删或误改可能导致服务异常。Harbor File 默认对系统目录操作做了保护，并提供“系统目录操作”开关。用户只有明确开启后，才可以对关键系统路径执行写入类操作。

插件还支持隐藏文件显示开关，适合在普通使用和高级维护之间切换。

## 多视图与个性化设置

Harbor File 支持多种视图模式，并可以保存用户偏好，包括默认视图、Home directory、是否显示隐藏文件、是否启用缩略图、是否允许系统目录操作等。

这些设置会写入 UCI 配置，重启页面后仍然保持。

## 适合哪些场景

Harbor File 适合这些用户和场景：

- 想在 OpenWrt 上像 Windows 一样管理文件的普通用户。
- 需要频繁上传、下载、编辑配置文件的维护人员。
- 使用软路由、旁路由、NAS 轻量存储或外接 USB 存储的用户。
- 经常安装 `.ipk` 或 `.apk` 插件包的 OpenWrt 玩家。
- 需要在网页里预览图片、PDF、视频或查看日志的用户。
- 希望减少 SSH 操作，但仍保留终端能力的高级用户。

Harbor File 把文件浏览、常用目录、磁盘展示、文件操作、文本编辑、多媒体预览、安装包管理、终端联动和安全控制整合到一个 LuCI 插件中。

安装它之后，OpenWrt 不再只是一个需要 SSH 才能深入管理的系统，而是可以通过浏览器完成大部分文件维护工作的设备。对普通用户来说，它降低了门槛；对高级用户来说，它节省了时间。
